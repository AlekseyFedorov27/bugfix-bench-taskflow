# taskflow (bugfix benchmark)

Небольшая Python-библиотека для управления задачами. Содержит **намеренно
внесённые баги**. Используется как тестовый репозиторий для bug-fixing агента.

## Установка

    pip install -e .
    pytest

На «чистом» клоне часть тестов падает — это ожидаемо.
Каждый падающий тест соответствует одному issue (см. `ISSUES.md`).

## Структура

- `models.py`   — dataclass `Task`
- `storage.py`  — in-memory хранилище
- `service.py`  — бизнес-логика
- `filters.py`  — пагинация, поиск, теги
- `stats.py`    — метрики
- `utils.py`    — утилиты (regex, даты, строки)
